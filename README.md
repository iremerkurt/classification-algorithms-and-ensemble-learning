# Machine Learning Classification and Ensemble Learning

A comparative study of different machine learning classification algorithms and ensemble learning methods using synthetically generated datasets.

## Project Overview

This project explores and compares various machine learning classification algorithms on synthetic datasets with different geometric structures. The main objective is to understand how individual classifiers perform on different classification problems and examine the advantages of ensemble learning methods.

The project includes data generation, exploratory data analysis, preprocessing, model training, performance evaluation, and decision boundary visualization.

## Objectives

- Generate synthetic datasets using Scikit-learn.
- Explore different binary classification problems.
- Implement and compare multiple classification algorithms.
- Visualize decision boundaries to understand model behavior.
- Investigate the performance of individual classifiers and ensemble learning methods.
- Evaluate models using training and test accuracy.

## Algorithms

- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

## Technologies

- Python
- Scikit-learn
- NumPy
- Pandas
- Matplotlib
- Seaborn
